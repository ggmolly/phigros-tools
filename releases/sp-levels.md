# SP levels, and a new patch for iPhone and iPad

On iPhone and iPad, this update needs the game patched again: if you updated in the game, Phigros++ is gone until you
patch it on the [Phigros++ page](/phigrospp?device=ios). On Android, it updates in the game as usual.

![](cover.svg)

## On iPhone and iPad

- Patch your copy of Phigros again on the [Phigros++ page](/phigrospp?device=ios), then install the new
  `Phigros++.ipa` with SideStore or AltStore as before.
- If you haven't updated in the game yet, skip the update and patch the game instead.
- This release hooks parts of the game your current patch doesn't cover, so the update alone left the game without
  Phigros++.

## SP levels

- A custom song can have an SP level, shown as **?** on the song list and the level bar, like the game's April Fools
  charts.
